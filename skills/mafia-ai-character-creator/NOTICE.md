# Notice

**Mafia AI Character Creator** is a public character-production skill. Its core is brand-neutral despite the project name.

The project is a substantial adaptation of the user-supplied `hatch-pet` skill distributed under Apache License 2.0. Version 1.2 preserves the original workflow strengths—canonical identity, deterministic extraction, visual QA, repair discipline, and reproducible packaging—while generalizing them to generated-art sprites, raster puppets, rigged vectors, and procedural animation.

Animation-system ideas were also informed by the MIT-licensed `JohnHeibel/ClaudeAnimationBase`, especially pure-time animation, deliberate key views, motion strips/contact sheets, and acting-oriented character systems. See `THIRD_PARTY_NOTICES.md` and `references/upstream-map.md`.
