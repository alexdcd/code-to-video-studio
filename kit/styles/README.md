# Free creative styles

The public registry intentionally lists exactly two creative styles:

| Style | Templates | Guide |
| --- | --- | --- |
| `cuaderno-vibrante` | `cuaderno-vibrante-9x16` | [Guide](cuaderno-vibrante/GUIA.md) |
| `editorial-motion` | `editorial-motion-16x9`, `editorial-motion-9x16` | [Guide](editorial-motion/GUIA.md) |

`starter-9x16` and `blank-16x9` are neutral technical templates. They help create a project without selecting a visual identity and do not count as creative styles.

Both styles are local, deterministic and use the files bundled in the Studio. Review `resource.json` and each `NOTICE.md` before redistributing a modified style.
